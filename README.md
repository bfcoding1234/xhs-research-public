# 小红书 Research · 本地调研工作台

面向内容运营、用户研究和产品调研的本地工具：把分散在关键词、作者和帖子里的线索整理成项目，并在保留原始依据的前提下生成数据摘要与 AI 辅助报告。

## 产品设计

- **素材可复用。** 作者和帖子集中管理，项目保存关联关系。同一条素材可以用在多个调研项目里；解除关联不会删除素材。
- **采集和结论分开。** 采集任务有自己的状态和结果；统计摘要固定数据口径，AI 报告在需要时再结合明细。报告应回查原文，不能替代研究判断。
- **长任务可以离开页面继续。** 采集与报告由后台任务执行，Web 和 CLI 通过同一套本地 API 查看状态与结果。

## 本地开始

需要 Python 3.9+；运行 Web 工作台前需按[工程说明](scripts/workbench/README.md)安装前端依赖并构建。可以先在仓库根目录运行 `python3 scripts/xhs_research.py --help` 查看已有命令。采集和生成报告需另行配置相应的本地工具与授权，详见[配置说明](docs/details/configuration.md)。完整测试需要相应环境和已构建前端，并非仅下载源码就会全部通过。
