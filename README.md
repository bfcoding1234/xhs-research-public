# 小红书 Research · 本地调研工作台

一个面向内容运营、用户研究和产品调研的本地工作台。它把原本分散在搜索结果、作者主页和帖子里的素材整理成可持续维护的调研项目，从发现线索、整理样本到生成报告，都能回到来源核对。

## 主要功能

| 功能 | 能做什么 |
| --- | --- |
| 关键词和作者调研 | 按关键词搜索帖子或相关作者，也可以按作者主页收集帖子。采集在后台运行，可查看进度和结果。 |
| 项目与素材管理 | 将帖子、作者和关键词归入项目。作者与帖子在全局素材库中去重，同一条素材可关联多个项目，无需复制。 |
| 数据摘要与 AI 辅助报告 | 分开生成程序统计的数据摘要和大模型报告。报告保留所用样本的快照和历史版本，便于回查结论依据。 |
| 对话与 Web 工作台 | 可通过 Agent Skill 发起任务，也可在 Web 工作台整理素材、查看进度和阅读报告。两个入口共享同一个本地服务和 SQLite 数据库。 |

**典型流程：** 以「通勤咖啡」调研为例，先创建主题项目，再用关键词找到相关笔记、按需补充作者样本；整理素材后生成数据摘要，如需进一步归纳，再生成 AI 报告，并回到代表帖子核对结论。不需要为了得到一份基础摘要就读取每篇帖子的完整详情。

## 本地开始

1. 在仓库根目录运行 `python3 scripts/xhs_research.py --help` 查看命令，运行 `python3 scripts/xhs_research.py check-env` 检查环境。
2. Web 工作台需要 Python 3.9+ 和 Node.js 20+。此快照不包含前端构建产物，请按[工程说明](scripts/workbench/README.md)安装前端依赖并构建，再从仓库根目录运行 `python3 scripts/xhs_research.py start`。
3. 数据采集需要配置可用的采集工具和相应授权；AI 关键词建议、图片理解和大模型报告需要另行配置 Codex CLI。程序统计的数据摘要不需要调用大模型。详见[配置说明](docs/details/configuration.md)。

服务仅监听本机回环地址；采集和调用模型可能需要联网。完整测试所需环境见[测试指南](docs/TESTING.md)。
