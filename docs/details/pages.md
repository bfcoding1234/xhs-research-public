本文是页面空间结构和关键交互的详细设计正文，不重复定义产品语义；术语、默认值和跨页面规则见 [PRODUCT_RULES.md](../PRODUCT_RULES.md)，同类页面的形成约束见 [页面规范](../page-specs/README.md)。尖括号中的内容（如 `〈作者名称〉`）表示运行时动态数据。

## 1. 蓝图符号

```text
┌─┐ / ├─┤        页面区块、卡片、表格或弹窗
[____________]   输入框
[选项 ▼]         下拉选择
【操作】          按钮
□ / ☑            未选中 / 已选中
○ / ●            单选未选中 / 已选中
‹ 1 2 3 ›        分页
↗                 在新标签页打开外部页面
…                 动态内容或省略的重复数据
〈名称〉           运行时数据
```

元素说明采用“业务名称优先”的写法：

```text
- 用户名称 [输入框] | 模糊搜索
- 新建用户 [主按钮] -> 打开新建抽屉
- 操作 [固定右侧] | 查看、编辑、删除
```

## 2. 全局页面框架

```text
┌──────────────────────┬──────────────────────────────────────────────────────────────┐
│ 小红书个人工作台      │ 固定顶部区域                                                  │
│                      ├──────────────────────────────────────────────────────────────┤
│ 个人                  │                                                              │
│ 作者                  │                     当前页面内容                              │
│ 项目                  │                                                              │
│ 任务中心              │                                                              │
│ 更多 ▾                │                                                              │
│   ├─ 帖子             │                                                              │
│   └─ 后台配置         │                                                              │
│                      │                                                              │
│ 固定左侧导航          │ 流式内容区                                                    │
└──────────────────────┴──────────────────────────────────────────────────────────────┘
```

- 导航 [固定左侧 / 240px] | 个人 → 作者 → 项目 → 任务中心 → 更多。
- 更多 [折叠菜单] | 收纳“帖子”和“后台配置”。
- 顶部 [固定]；内容区 [Fluid]；全局不显示页脚。
- `/` -> 独立官网；`/overview` -> 兼容重定向到 `/my-projects`；工作台布局只出现在业务路由。
- 列表、详情和设置页统一支持加载状态；请求失败时展示错误信息和重试入口。

- 顶部导航 [页内按钮] | “能力”“流程”“场景”平滑滚动到对应区块；用户偏好减少动效时使用即时滚动。
- 进入工作台、开始研究、底部 CTA [站内链接] -> `/my-projects`。
- Hero 右侧是工作流静态示意，不读取真实任务或数据库，不提供交互式任务操作。

- 页面独立维护品牌样式、页头和页脚，不显示 ProLayout 导航；进入时设置官网标题，离开时恢复工作台标题。
- 本页没有业务 API、加载态或业务错误态；所有示例数字和任务均为产品说明，不代表真实数据。

```text

│ 〈报告标题〉          [版本 n] [制作 HTML 演示稿]│ 快照帖子                         │
```

- 生成数据摘要 [按钮] -> 基于当前作者数据库快照生成确定性描述统计，不创建任务。
- 生成大模型报告 [主按钮] -> 配置报告标题、补充要求和数据来源并创建任务。数据摘要与当前明细可复选且至少选一项；有摘要时默认同时选中最近版本和当前明细。当前明细下的作者与帖子至少开启一个；帖子默认选择“有代表性的帖子”（20%，最多 20 篇），也可选择“更多帖子”（50%）或“全部帖子”（100%），界面按当前帖子总数显示实际篇数。帖子内容独立选择基础信息、正文、OCR 文本和大模型理解文本，默认选择前三项。同时选中两类来源时，摘要负责统计口径，明细负责案例。
- 制作 HTML 演示稿 [按钮] -> 仅已完成且有正文的大模型报告可用；选择精简、标准或完整篇幅并创建持久化任务。完成后在源报告标题下、长篇 Markdown 正文之前按版本预览或下载自包含 HTML。
- 报告为空 [空状态] | 按当前报告类型提供首次生成入口。
- 任务已创建 [成功弹窗] | 留在当前页或查看任务详情。
