# 页面形成规范

## 文档定位

本目录对应传统开发中的 UI 设计规范、页面模式规范和设计系统 Pattern。它规定一类页面如何形成，不规定某个业务对象的具体字段或权限。

| 页面类型 | 当前规范 | 状态 |
| --- | --- | --- |
| 列表页 | [列表页规范](./list-page.md) | 已建立，作为第一份页面模式规范 |
| 详情页 | 待建立 | 复用列表页中的状态、操作风险和无障碍原则 |
| 创建 / 编辑表单 | 待建立 | 后续按实际项目需求沉淀 |
| 设置页 | 待建立 | 后续按实际项目需求沉淀 |
| 仪表盘 / 报告页 | 待建立 | 后续按实际项目需求沉淀 |

## 使用关系

```text
PRODUCT_RULES.md        决定业务语义和默认行为
页面详细设计            决定具体页面展示什么
page-specs/             决定同类页面怎样组织和交互
ENGINEERING_GUARDRAILS  决定实现约束和验证门禁
```

当项目中的同一种页面模式已经经过多次真实实现和验收，且规则不依赖本项目业务对象时，才评估提升到通用开发 Skill。
